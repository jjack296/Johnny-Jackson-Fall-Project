Introduction

Hypertext Transfer Protocol (HTTP) is the application-level protocol that lets web clients and servers exchange representations of resources. Browsers use HTTP to request HTML pages, images, style sheets, scripts, video segments, API data, and many other resources.

HTTP began around 1990 as a very small protocol for retrieving hypertext documents. As the Web grew, HTTP gained headers, status codes, methods, persistent connections, caching, encryption, multiplexing, compression, and more efficient transport. This website follows that evolution from HTTP/0.9 through HTTP/3.

Key Terms

HTTP: Hypertext Transfer Protocol   •   Client: software requesting a resource   •   Server: software returning a response   •   QUIC: the secure multiplexed transport used by HTTP/3.
