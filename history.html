How HTTP Evolved

The World Wide Web was created between 1989 and 1991. HTTP grew along with it, changing from a one-line request protocol into a modern system designed for security, speed, and many simultaneous resources.

HTTP Timeline

1989–1991: The Web Is Born

Tim Berners-Lee proposed the World Wide Web in 1989. By 1990, the first browser, web server, and early HTTP implementation were working, and the Web became publicly available in 1991.

HTTP/0.9: The One-Line Protocol

The earliest HTTP was extremely simple. A client sent a request such as GET /page.html, and the server returned HTML. There were no headers, status codes, or content types.

1996: HTTP/1.0

RFC 1945 documented HTTP/1.0. It added version and status lines, headers, content types, and methods such as POST and HEAD. Many requests still required separate TCP connections.

1997: HTTP/1.1

HTTP/1.1 introduced persistent connections, required the Host header, and improved caching and content negotiation. It reduced the cost of repeatedly opening connections and remains widely supported.

2015: HTTP/2

HTTP/2 introduced binary framing, multiple streams over one connection, and HPACK header compression. Multiplexing allowed several HTTP exchanges to share a connection instead of waiting for one another at the HTTP layer.

2021–2022: QUIC and HTTP/3

QUIC was standardized in 2021. HTTP/3, standardized in 2022, maps HTTP semantics onto QUIC rather than TCP. QUIC provides independent streams, integrated TLS 1.3 security, faster setup, and connection migration.
