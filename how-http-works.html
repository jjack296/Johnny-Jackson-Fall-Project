The HTTP Conversation

HTTP is an application-level protocol. A client asks for a resource, and a server sends a response. The resource could be an HTML document, image, JSON data, video, file, or the result of an action.

HTTP itself is stateless: each request can be understood independently. Websites add remembered state with technologies such as cookies, session identifiers, and authentication tokens.

Example Request

GET /index.html HTTP/1.1
Host: example.com

The request contains a method, resource path, HTTP version, and headers.

Example Response

HTTP/1.1 200 OK
Content-Type: text/html

<html>...</html>

The response includes a status, headers, and usually a message body.

Status Codes

  • 1xx: Informational
  • 2xx: Success
  • 3xx: Redirection
  • 4xx: Client error
  • 5xx: Server error

Caching

Browsers and CDNs can reuse responses instead of downloading the same content every time. Headers such as Cache-Control, ETag, and Last-Modified help determine whether stored content can be reused.

HTTPS

HTTPS protects HTTP during transport using TLS. Encryption helps prevent outsiders from reading traffic, while certificates help clients authenticate the server. HTTP/3 uses QUIC with TLS 1.3 integrated into the transport.
