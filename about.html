Website Project

Topic: The Evolution of HTTP

The project covers HTTP basics, protocol history, requests and responses, caching, HTTPS, HTTP/2, HTTP/3, and QUIC.

What I Learned

Researching HTTP showed me that the Web depends on layers of technology working together. HTTP defines the meaning of requests and responses, while transports such as TCP and QUIC determine how those messages move across networks. Building this website also gave me practice turning research into organized web content and applying one consistent design across several pages.
